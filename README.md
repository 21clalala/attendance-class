# 수업 출결 체크

교과선생님이 QR로 접속해 현재 교시의 없는 학생을 표시하면, 담임 휴대폰(ntfy)으로 알림이 갑니다. 여러 반을 지원합니다.

- 관리자 페이지: `https://21clalala.github.io/attendance-class/admin.html`
- 교과선생님 페이지: 반마다 다른 QR 주소 (관리자 페이지 **설정·QR·명단** 탭)

## 파일 구성
| 파일 | 용도 |
|---|---|
| `index.html` | 교과선생님 페이지 (QR로 접속) |
| `admin.html` | 관리자 페이지 (로그인) |
| `config.js` | Supabase 주소·공개 키 |
| `neis-parse.js` | 나이스 일일출석부 엑셀 해석 |
| `supabase/schema.sql` | 새로 설치할 때 한 번 실행하는 전체 SQL |
| `supabase/migrate-00N.sql` | 기존 설치를 업데이트하는 SQL (번호 순서대로 한 번씩) |

GitHub에 올라가는 파일에는 학생 정보가 없습니다. 명단과 출결은 모두 Supabase에만 저장됩니다.

---

## 권한
| 구분 | 할 수 있는 것 |
|---|---|
| **전체 관리자** | 모든 반 관리, 반 추가·삭제, 반별 관리자 등록, 학교 공통 시정·단축수업 수정 |
| **반 관리자(담임)** | 자기 반의 명단·시간표·교체대강·나이스 업로드·QR·알림 토픽 |
| **교과선생님** | 로그인 없음. QR로 접속, 처음 한 번 이름 선택, 본인 수업 시간에만 입력 |

## 반 추가하기 (전체 관리자)
1. 관리자 페이지 → **반·관리자** 탭 → 반 이름(예: `3-5`) 입력 → **반 추가**
2. 같은 탭에서 그 반 담임 이메일 **등록**
3. 담임선생님께 관리자 페이지 주소를 알려 주고 **처음이신가요? 계정 만들기**로 비밀번호를 정하게 안내
4. 담임선생님(또는 전체 관리자)이 그 반을 선택해서
   - **설정·QR·명단**: 명단 입력, 휴대폰 ntfy 앱에서 토픽 구독 → 테스트 알림, QR 인쇄
   - **시간표·시정**: 요일×교시 선생님 이름 입력

> 등록되지 않은 이메일은 계정을 만들 수 없습니다.

## Supabase 설정 (여러 반 사용 시 한 번)
**Authentication → Sign In / Providers → Email**
- **Allow new users to sign up**: 켜기 (등록된 이메일만 가입되도록 DB에서 막혀 있음)
- **Confirm email**: 끄기 (Supabase 기본 메일은 외부 주소로 잘 가지 않음)

가입 제한이 제대로 걸렸는지 확인 (SQL Editor):
```sql
select count(*) from pg_trigger where tgname = 'attend_invite_only';
```
결과가 `1`이면 정상입니다. `0`이면 가입을 켜지 말고, 담임 계정은 **Authentication → Users → Add user**에서 직접 만들어 주세요.

비밀번호를 잊은 선생님: **Authentication → Users**에서 그 계정을 삭제한 뒤, 다시 **계정 만들기**를 하면 됩니다 (관리자 등록은 그대로 유지).

## 컴시간알리미 연동 (전체 관리자, 한 번)
전체 학년·반의 이번 주·다음 주 시간표(수업 교환 반영)를 평일 07:10~16:10 사이 1시간마다 자동으로 받아 옵니다.

1. **Supabase 비밀 키를 GitHub에 등록**
   - Supabase → **Project Settings → API Keys** → **Secret keys**의 키 복사 (`sb_secret_…`, 없으면 legacy `service_role` 키)
   - GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `SUPABASE_SERVICE_KEY`, Secret: 복사한 키 → **Add secret**
   - 이 키는 채팅·코드·config.js 어디에도 넣지 마세요.
2. 관리자 페이지 **컴시간** 탭 → 학교 이름 저장 (예: `용인고등학교`)
3. GitHub 저장소 → **Actions → 컴시간 시간표 동기화 → Run workflow** (첫 실행)
4. 관리자 페이지 **컴시간** 탭에서 결과 확인 → **선생님 번호 → 이름**에 실명 입력
   (컴시간알리미 프로그램의 교사 목록 번호와 같습니다. "07 김영대"처럼 붙여 넣기 가능)

선생님 결정 순서: **직접 입력한 교체·대강 > 컴시간 > 직접 입력한 기본 시간표**.
동기화가 실패해도 마지막으로 받은 자료와 직접 입력한 시간표로 계속 동작합니다.
(비공식 연동이라 컴시간 쪽 구조가 바뀌면 멈출 수 있습니다. GitHub는 저장소에 60일간 변경이 없으면 예약 실행을 멈추니, 그때는 Actions 탭에서 다시 켜 주세요.)

## 매일 사용 (담임)
- 아침(또는 중간에): 나이스 **일일출석부** 엑셀 내려받기 → **나이스 업로드** → 미리보기 확인 → 적용
  (다른 반 파일이면 경고가 뜨고 적용되지 않습니다)
- 교체·대강: **날짜별 변경** 탭의 교체·대강 칸 (그 반만 적용)
- 단축수업·휴업일: **날짜별 변경** 탭 (전체 관리자, 모든 반에 적용)
- 확인: **출석부** 탭 (교과선생님 입력이 실시간 반영, 빨간 "/"·"출석"을 누르면 삭제)

## 동작 규칙
- 교시는 **수업 시간 안에서만** 열립니다 (예: 3교시 10:50~11:40). 시각은 서버의 한국 시간 기준.
- 교과선생님은 처음 접속 때 이름을 고르고, **그 이름이 시간표에 있는 교시에만** 입력할 수 있습니다 (서버에서도 확인).
- 나이스 "/"도 교과선생님이 해제할 수 있고(→ "출석 확인" 알림), 변경 없이 저장하면 "확인"으로 기록됩니다.
- 이름 뒤 `(자습반)` 같은 괄호는 교과선생님 화면에 표시, `(위탁)`은 입력·알림 제외.
- 체험용 주소(`…&demo=1`): 가짜 명단, 출결 기록 없이 `[체험]` 알림만.

## 알아 둘 점
- **Free 프로젝트는 7일간 사용이 없으면 일시정지**됩니다. 방학이 끝나면 대시보드에서 Resume 하세요.
- QR이 학생에게 노출되면 그 반의 **설정·QR·명단 → 주소 새로 만들기** 후 다시 인쇄하세요.
- 알림은 ntfy 공용 서버(ntfy.sh)를 거칩니다. 토픽 이름은 추측할 수 없게 자동 생성됩니다.
