예정된 변경

교과선생님 접속 QR

주소를 새로 만들면 이전 QR은 더 이상 열리지 않습니다. QR이 학생에게 노출됐을 때 사용하세요.

체험용 주소 — 수업 시간과 상관없이 가짜 명단으로 열리고, 저장하면 [체험] 알림만 갑니다(출결 기록 없음).

담임 선생님

담임 시간(기본: 금요일 5·6교시)에는 이 이름이 교과선생님 자리에 들어갑니다. 교과선생님 화면에서 고르는 이름과 똑같이 실명으로 넣으세요.

알림 (ntfy)

한 줄에 "번호 이름". 이름 뒤에 (자습반)처럼 괄호로 적으면 교과선생님 화면에 그 표시가 뜹니다. (위탁)은 입력·알림에서 제외됩니다. 목록에서 지운 번호는 명단에서 삭제됩니다.

컴시간알리미 연동

동기화 토큰 — GitHub 저장소 Settings → Secrets and variables → Actions 에 이름 COMCI_SYNC_TOKEN 으로 넣으세요. 이 토큰으로는 컴시간 시간표만 쓸 수 있습니다.

평일 아침 07:10에 하루 한 번 자동으로 받아 옵니다. 그 뒤에 생긴 교환은 [날짜별 변경]에 직접 넣거나 아래처럼 바로 받으세요. 바로 받으려면 GitHub 저장소 → Actions → 컴시간 시간표 동기화 → Run workflow.

선생님 번호 → 이름

컴시간 웹에는 이름이 가려져 보일 수 있습니다. 컴시간알리미 프로그램의 교사 목록 번호와 같은 번호입니다. 실명을 넣으면 교과선생님 화면·시간표에 그 이름이 쓰입니다.
