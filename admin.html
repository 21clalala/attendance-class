    증빙서류 미제출

    이 반 담임선생님 휴대폰의 ntfy 앱에서 아래 토픽을 구독하세요.

    학생 명단

    한 줄에 "번호 이름". 이름 뒤에 (자습반)처럼 괄호로 적으면 교과선생님 화면에 그 표시가 뜹니다. (위탁)은 입력·알림에서 제외됩니다. 목록에서 지운 번호는 명단에서 삭제됩니다.

    사용 도움말

    교과선생님은 수업 시간에 QR로 출결을 체크하고, 담임선생님은 이 페이지에서 확인·입력한 뒤 나이스에 반영합니다.
    1. 처음 한 번 설정2. 매일 할 일3. 나이스에 반영하기 4. 출결신고서·증빙서류5. 시간표 변경6. 교과선생님 사용법 7. 출석부 읽는 법8. 자주 묻는 질문

    1. 처음 한 번 설정

    1
    학생 명단 가져오기 (나이스 파일 한 번만)
    나이스에서 일일출석부 파일을 내려받아 [나이스 업로드]에 한 번 끌어다 놓으면 번호·이름이 채워집니다. 그다음부터는 매일 올릴 필요가 없습니다.
    나이스→학급담임→학적→출결관리→일일출결관리→출력→디스크 모양→XLS data
    자습반·위탁 학생은 [우리 반 설정] → 학생 명단에서 이름 뒤에 (자습반), (위탁)을 붙이고 저장하세요. 재실 인원에서 빠집니다. 전학 등으로 명단이 바뀌면 거기서 고치세요.
    2
    휴대폰으로 알림 받기
    App Store 또는 Play 스토어에서 ntfy 설치 → 앱에서 + → [우리 반 설정]에 있는 토픽 이름 입력 → Subscribe → [테스트 알림]을 눌러 알림이 오는지 확인하세요.
    3
    QR을 종이 출석부에 붙이기
    [우리 반 설정] → QR 인쇄. 학생이 찍지 않도록 출석부 안쪽에 붙이는 것을 권합니다.
    4
    나이스 반영 버튼 설치
    아래 3. 나이스에 반영하기의 설치 순서를 따라 하세요.

    2. 매일 할 일 — [오늘 출석부]에서 직접 입력

    • 교시 칸을 누르면 "/"가 찍히고, 다시 누르면 지워집니다. 교과선생님이 찍은 "/"도 담임이 바꿀 수 있고 기록이 남습니다.
    • 마감 칸을 누르면 종류(결석·지각·조퇴·결과)와 구분(질병·미인정·기타·출석인정), 사유를 고르는 창이 뜹니다. 결석을 적용하면 조회~종례가 모두 "/"로 채워지고, 지각·조퇴·결과는 해당 교시를 직접 눌러 "/"를 찍습니다.
    • 비고 칸을 누르면 바로 고칠 수 있습니다. Enter 저장, Esc 취소.
    • 조회 시간(08:00~08:50)에는 교실 QR을 찍어 휴대폰으로도 입력할 수 있습니다. 담임 입력이라 알림은 가지 않습니다.
    • 날짜를 바꾸면 지난 날짜도 같은 방법으로 고칠 수 있습니다.
    • 나이스에서 직접 고친 날짜를 앱에 맞추려면 그 날짜의 나이스 파일을 [나이스 업로드]에 올리세요. 앱 입력과 다른 학생만 골라서 바꿀 수 있습니다.

    3. 나이스에 반영하기

    앱에 입력한 출결을 하루씩 나이스 일일출결관리 화면에 채워 줍니다. 채우기만 하고 [저장]은 선생님이 직접 누릅니다. 나이스를 쓰는 컴퓨터(크롬·엣지)에서 합니다.

    설치 (처음 한 번)

    1
    즐겨찾기 막대 켜기
    나이스를 여는 브라우저에서 Ctrl + Shift + B
    2
    [출결 반영] 버튼 설치
    나이스 반영 도구 페이지를 열고, 초록 [출결 반영] 버튼을 즐겨찾기 막대로 끌어다 놓습니다(누르지 말고 끌기). 한 번 설치하면 다시 설치할 필요가 없습니다.
    3
    같은 브라우저에서 이 페이지에 로그인
    나이스를 엣지로 쓰면 엣지에서, 크롬으로 쓰면 크롬에서 로그인해 두세요. 로그인은 유지됩니다.

    반영 (하루씩)

    1
    나이스 화면 열기
    나이스 → 학급담임 → 출결관리 → 일일출결관리(담임용) → 날짜 선택 → [조회]
    2
    즐겨찾기의 [출결 반영] 클릭
    옆에 반영 창이 뜹니다. 처음에 "팝업 차단" 안내가 나오면 주소창 오른쪽 아이콘에서 허용한 뒤 다시 누르세요.
    3
    비교표 확인
    나이스와 앱이 다른 학생만 나옵니다. 채움 = 나이스가 비어 있어 새로 넣음, 바꿈 = 앱에서 바뀐 내용, 충돌 = 나이스에 이미 다른 내용이 있음. 충돌 학생은 "나이스 그대로 두기 / 앱 내용으로 바꾸기" 중 고르세요(기본은 나이스 그대로).
    4
    [나이스에 채우기] → "이대로 반영할까요?" → [반영]
    나이스 화면에 채워지고, 채운 학생 줄이 선택(색칠)됩니다. 반영 창이 나이스를 다시 읽어 제대로 들어갔는지 대조해 줍니다.
    5
    나이스에서 확인하고 [저장]
    이상하면 저장하지 말고 나이스 [조회]를 다시 누르세요. 채운 내용이 사라지고 원래대로 돌아갑니다.
    6
    [조회] → [다시 확인] → [반영 완료]
    저장 후 나이스 [조회]를 한 번 더 누르고 반영 창의 [다시 확인]으로 실제 저장됐는지 확인한 뒤 [반영 완료]. [오늘 출석부] 제목 줄에 "나이스 반영 ✓"가 남습니다.
    • 반영 창은 나이스의 [저장]·[출결마감]을 절대 누르지 않습니다.
    • 출결마감된 날짜는 채우지 않습니다. [마감취소] 후 다시 하세요.
    • 나이스와 앱의 번호·이름이 다르면 멈춥니다. 명단을 맞춘 뒤 다시 하세요.

    4. 출결신고서·증빙서류

    • 비고에 "미제출"이 있으면 [출결신고서(증빙서류)] 메뉴에 월별·서류별(출결신고서/응시확인증/보고서)로 모입니다. 대학별고사는 응시확인증, 교외체험학습은 보고서로 자동 구분되고, 마감 창에서 직접 고를 수도 있습니다. 마감 창의 "출결신고서 미제출"을 체크해도 되고, 비고에 직접 써도 됩니다. 신고서가 필요한 경우(질병, 출석인정 중 생리통·경조사·법정감염병)만 모이고, 미인정·기타·그 밖의 출석인정(대회 등)은 빠집니다.
    • 신고서 출력: [출결신고서(증빙서류)] → [출결신고서 만들기]를 누르면 그 달 미제출 학생의 신고서를 한 파일(HWPX)로 만듭니다. 한 날짜만 필요하면 [오늘 출석부] → [신고서 출력]. 한글에서 열어 인쇄하세요. 사유 체크는 비고 괄호 안 내용으로 자동 체크되고, [고치기]로 바꿀 수 있습니다. 생리통 출석인정은 학부모확인서가 뒤에 붙습니다.
    • 신고서를 받으면 [제출 완료]를 누르세요. 목록에서 사라집니다(잘못 눌렀으면 [제출 완료 보기]에서 취소).
    • 남은 미제출이 있으면 수업이 있는 날 아침 08:00에 휴대폰으로 알림이 옵니다.

    5. 시간표 변경 (교체·대강·단축수업)

    • 시간표와 수업 교환은 매일 아침 컴시간알리미에서 자동으로 받아 옵니다.
    • 급한 교체·대강: [시간표 변경] → 날짜 선택 → 그 교시 교체·대강 칸에 선생님 이름 → 저장.
    • 단축수업: 같은 화면에서 시각을 고치거나 수업 없는 교시의 체크를 끄고 저장. 우리 반에만 적용됩니다.
    • 담임 시간(기본: 금요일 5·6교시)과 조회 시간에는 담임선생님이 체크합니다. 반·관리자에 담임 이름이 있어야 합니다.

    6. 교과선생님 사용법 (전달용)

    1. 종이 출석부의 QR을 휴대폰으로 찍습니다.
    2. 처음 한 번만 본인 이름을 고릅니다. 잘못 골랐으면 오른쪽 위 [변경].
    3. 본인 수업 시간에만 그 교시 칸이 열립니다.
    4. 없는 학생 줄을 누르고 [저장]. 회색 "/"(담임이 미리 표시한 학생)가 교실에 있으면 눌러서 해제합니다.
    5. 변경이 없어도 [저장]을 누르면 "확인"으로 기록됩니다.

    7. 출석부 읽는 법

    /담임이 입력
    /교과선생님이 찍음 → 알림
    출석"/"를 교과선생님이 해제
    /나이스 파일에서 올라온 값

    재실 인원 = 재적 − 자습반 − 위탁 − "/" 표시 학생. 오른쪽 [최근 입력]에 누가 언제 무엇을 바꿨는지 남습니다.

    8. 자주 묻는 질문

    알림이 오지 않아요

    ntfy 앱에 구독한 토픽 이름이 [우리 반 설정]의 토픽과 한 글자도 다르지 않은지 확인하고, [테스트 알림]을 다시 눌러 보세요. 휴대폰 설정에서 ntfy 알림이 꺼져 있지 않은지도 확인하세요.

    교과선생님 이름이 목록에 없어요

    우리 반에 들어오는 선생님만 나옵니다. 대강이면 [시간표 변경]에 그 선생님 이름을 넣으면 목록에 생깁니다.

    [출결 반영]을 눌러도 아무 반응이 없어요

    나이스 일일출결관리(담임용) 화면에서 [조회]한 뒤 눌러야 합니다. 팝업 차단 아이콘이 주소창에 보이면 허용하세요. 반영 창에 "로그인되어 있지 않습니다"가 나오면 같은 브라우저에서 이 페이지에 로그인하세요.

    반영 창에 "충돌"이 많이 나와요

    나이스에 이미 직접 입력해 둔 날이면 그렇습니다. 나이스 내용이 맞으면 "나이스 그대로 두기"를, 앱 내용이 맞으면 "앱 내용으로 바꾸기"를 고르세요.

    QR이 학생에게 노출됐어요

    [우리 반 설정] → [주소 새로 만들기] 후 QR을 다시 인쇄하세요. 이전 QR은 바로 열리지 않게 됩니다.

    컴시간알리미 연동

    동기화 토큰 — GitHub 저장소 Settings → Secrets and variables → Actions 에 이름 COMCI_SYNC_TOKEN 으로 넣으세요. 이 토큰으로는 컴시간 시간표만 쓸 수 있습니다.
