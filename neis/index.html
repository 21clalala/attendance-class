나이스 반영 도구

설치 (한 번만)

  1. 나이스를 여는 브라우저(크롬 또는 엣지)에서 이 페이지를 엽니다.
  2. 즐겨찾기 막대를 켭니다: Ctrl+Shift+B
  3. 아래 초록 버튼을 즐겨찾기 막대로 끌어다 놓습니다. (누르지 말고 끌기)
  4. 같은 브라우저에서 출결 앱 관리자 페이지에 로그인해 둡니다.

출결 반영

이 버튼은 앞으로 기능이 바뀌어도 다시 설치할 필요가 없습니다.

매일 반영하기

  1. 나이스 → 학급담임 → 출결관리 → 일일출결관리(담임용)에서 날짜를 고르고 [조회]
  2. 즐겨찾기의 [출결 반영] 클릭 → 옆에 반영 창이 뜹니다 (팝업 차단 안내가 나오면 허용)
  3. 비교표를 보고, 충돌 학생은 "나이스 그대로 / 앱 내용으로" 선택
  4. [나이스에 채우기] → "이대로 반영할까요?" 확인 → [반영]
  5. 나이스 화면을 확인하고 [저장]은 직접 누르기
  6. 나이스 [조회]를 한 번 더 누르고 반영 창의 [다시 확인] → [반영 완료]

반영 창은 나이스의 [저장]·[출결마감]을 절대 누르지 않습니다. 저장하기 전에 나이스에서 [조회]를 다시 누르면 채운 내용은 사라집니다.

문제가 생겼을 때

아래 버튼도 즐겨찾기에 끌어다 놓고, 나이스 화면에서 눌러 나온 결과를 보내 주세요. 읽기만 하고, 이름·주민번호 등은 가려집니다.
